# prepexflow


Open-source platform for SSC and competitive exam students.

## Features

- Latest SSC/Government job news
- Current affairs
- AI summaries
- Bookmark system
- Quiz generation
- Student dashboard

## Tech Stack

- Next.js
- FastAPI
- PostgreSQL
- Tailwind CSS
- OpenAI/Gemini API

## Getting Started

```bash
git clone repo-url
cd prepexflow
```
